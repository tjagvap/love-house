恋爱小屋 V3 修复摘要

1. 修复主脚本因 Three.js CDN 加载失败而提前中断的问题。
2. Three.js 多线路加载，并在未加载成功时提供可旋转缩放的兼容房间预览。
3. 修复因脚本中断而未注册的房间/风格/调色/墙贴交互按钮。
4. 物体 hover 改为局部背景图像放大，不再出现阴影或泛光。
5. 恢复漂流瓶初始化和沿河道移动；增加河面动态水光。
6. 增加树叶微风摆动效果。
7. 增加天气系统和昼夜交替；默认白天 10:00。
8. 夜晚变暗，阳台暖光亮起，两位角色剪影移动到阳台场景。

恋爱小屋 V4 升级摘要
1. 漂流瓶改为 Canvas 拟真渲染，修正百分比坐标与千分比坐标系不一致导致瓶子堆叠在左上角的问题。
2. 瓶子增加玻璃渐变、软木塞、纸条、倒影、尾迹波纹、透视缩放与随波起伏，保留点击留言。
3. 修正河面水光线坐标，四条光带沿真实河道延伸。
4. 用同构图 AI 夜景照片替代黑色蒙层；草坪两人移除，室内亮暖光并加入窗内剪影。
5. 悬停放大按昼夜切换底图；昼夜状态连续插值控制夜景淡入。
6. 新增 Spring Boot + Thymeleaf 全栈工程 java-app/，结构化数据由 Java 后端持久化到 data/state.json，视觉效果与静态版一致。

恋爱小屋 V5 拟真交互升级摘要
1. 悬停改为“物体连轮廓整体放大浮起”：按物体轮廓从昼夜底图裁出后整体放大并加阴影，替代放大镜式局部纹理放大。
2. 漂流瓶支持绑定照片与留言：瓶内可上传照片或从相册选择，文字与照片一起封存查看；瓶身用彩点区分含照片/留言。
3. 新增拟真照片房间编辑器（默认）：三张照片级空房间背景 + 18 件去背家具，家具可自由拖动、缩放、旋转、复制、删除。
4. 房间可在“拟真照片房间”与“3D 毛坯房间”间切换；3D 模式家具现支持拖动移动、旋转、缩放与删除选中。
5. 新增素材 assets/rooms/（3 张房间背景 + 18 件透明家具 PNG），并同步到 Java 静态资源；恢复 Java 模板的后端状态同步逻辑。

恋爱小屋 V6 统一拟真创作空间摘要
1. 悬停改为纯净的沿物体轮廓等比例放大：移除阴影、发光和位置偏移，仅保留约 14% 的平滑放大。
2. 移除“拟真照片房间 / 3D 毛坯房间”模式切换，房屋面板收敛为唯一的拟真空间；旧 3D 调色与墙贴工具隐藏但保留历史数据兼容。
3. 每个房间（客厅/卧室/卫生间）可上传自定义背景并恢复默认背景。
4. 每个房间可上传自定义家具/装饰素材（PNG/JPG/WEBP），素材进入库后可反复摆放，也可从库中删除。
5. 已摆放素材新增左右翻转、上移一层、下移一层；默认摆放位置自动错开，避免堆叠。
6. 自定义背景与素材存入 IndexedDB（新增 roomAssets / roomBgs 存储，数据库升级到 v3）；房间布局继续同步到 Java 后端。

恋爱小屋 V7 真三维房间摘要
1. 房间从照片背景彻底改为 Three.js 真三维场景：开放式房间、门窗、装饰画、程序化木纹与瓷砖、阴影和暖灯，支持旋转视角与缩放。
2. 新增三维家具库：三房间各 8 件立体家具，可点击选中、拖动移动、旋转、缩放、复制、删除；材质与灯光可实时切换。
3. 三维家具布局存到 state.room.f3d，继续同步 Java 后端 data/state.json。
4. 内置本地 assets/three.min.js，CDN 不可用时仍可渲染三维房间。
5. 树木悬停改用透明抠图素材 tree_day.png / tree_night.png，只放大树本身，无背景块与多余装饰，昼夜自动切换。

恋爱小屋 V8 第一人称游戏化房间摘要
1. 房屋新增“第一人称漫游”模式：点击视口右上角进入，鼠标锁定环视，WASD / 方向键行走，Shift 快走，带轻微行走视点起伏。
2. 漫游时自动补齐右墙、带门洞的前墙和天花板，形成完整室内空间；编辑视角仍保持开放式俯视，方便拖拽布置。
3. 新增游戏 HUD：准星、房间名与家具数量、按键提示、交互提示条、实时小地图（玩家朝向与家具位置）；Esc 暂停后可点击画面继续或返回编辑。
4. 准星创作：在家具库点选模型后出现半透明放置预览，准星对准地面左键落位；R 旋转预览角度，右键取消。
5. 漫游中准星对准家具按 E 选中，Q/R 旋转、[ ] 缩放、Del 删除，所有改动继续写入 state.room.f3d 并同步 Java 后端。
6. 静态版与 Java Thymeleaf 模板同步，保留 __SERVER_MODE__ 状态同步逻辑。

恋爱小屋 V9 默认游戏入口 + 受限环境媒体保存摘要
1. 进入房屋面板即默认第一人称漫游，不需再手动点“进入”；编辑视角保留为可切换选项。
2. 漫游 HUD 新增“🎨 装修”快捷面板：墙面五色、地面三种材质、暖灯开关，均可在行走中即时生效并自动保存。
3. IndexedDB 不可用时不再提示“暂不能保存”：自动降级为压缩本地存储，照片按最长边 1100px/JPEG 压到 localStorage，刷新后仍在；视频因体积限制仅本次会话可看。
4. 媒体读取统一走 mediaUrl()，兼容 IndexedDB Blob 与降级 dataURL；房间素材、墙贴素材同样受益。

恋爱小屋 V10 墙贴回归新三维房间摘要
1. 修复历史墙贴（含 Hello Kitty 主题）在切成新 3D 房间后不再显示的问题：新增 f3dRenderWallArts()，把 state.room.wallArts 渲染成带透明纹理的平面贴到新房间墙面，编辑视角与第一人称都能看到。
2. 墙贴纹理改用独立缓存 f3dArtTextures + 显式 Image 加载，图片就绪后 needsUpdate 自动刷新，避免复用旧场景空纹理导致贴图变空白。
3. 漫游装修面板新增墙贴管理：Hello Kitty / 库洛米 / 玉桂狗 / 人鱼汉顿主题素材点击即贴、上传自定义图片、已贴墙贴缩略图一键移除。
4. 内置主题墙贴直接引用 assets/wall_stickers 路径，不依赖 fetch（本地 file:// 打开也能用）；删除时同步清理纹理缓存。
5. 静态版与 Java 模板同步。

恋爱小屋 V11 手机触屏 + 上线 GitHub Pages 摘要
1. 手机/平板完整可玩：检测触屏后自动启用虚拟摇杆（左下）+ 九宫格触屏按钮（家具/装修/选中/摆放/旋转/取消/缩小/放大/删除）+ 拖动环视，安卓、iOS、微信内置浏览器均可用。
2. 游戏内新增「🪑 家具」浮层：第一人称漫游中也能从家具库点选家具生成半透明放置预览（此前漫游模式会把家具库一起隐藏，导致无法添加家具）。
3. 触屏设备上面板改为整屏 fixed，房屋 3D 视口占满整屏高度，不再被正方形主画面裁切；配合 safe-area 适配刘海屏。
4. 修复所有面板打开时顶部工具栏浮在面板之上的问题：面板打开时 topbar 自动淡出（桌面同样受益）。
5. 新增微信分享与 PWA 支持：og:title/og:description/og:image 分享卡片、manifest.json、apple-touch-icon、可添加到手机主屏幕全屏运行；图标由程序生成（assets/icon-192/512、apple-touch-icon）。
6. 部署：仓库 tjagvAP/love-house 推送 main 分支，GitHub Pages（https://tjagvap.github.io/love-house/）自动构建，HTTPS 强制；静态版即为线上版本，数据仍存各设备本地。
7. Java 模板与 static 资源（manifest、图标）同步，脚本语法校验通过。
