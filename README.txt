恋爱小屋 · 3D 自由装修与墙贴素材库

项目文件
- index.html：网站主程序
- bg.jpg：河畔场景背景（请与 index.html 放在同一目录）
- style_reference.png：中式、美式、欧式、现代四种室内风格参考图
- material_reference.png：四种风格的材质与配色参考图
- assets/wall_stickers/：透明背景墙贴素材库

启动方式
1. 解压整个 ZIP 文件。
2. 确保 index.html 和 bg.jpg 位于同一目录。
3. 在该目录打开终端并运行：python -m http.server 8000
4. 浏览器访问 http://localhost:8000
5. 3D 房间依赖 Three.js CDN，首次使用需要联网。

墙贴素材库
- 内置 4 个主题：Hello Kitty、库洛米、玉桂狗、人鱼汉顿。
- 每个主题有 1 张透明背景整组贴纸图，并拆出了可单独摆放的 PNG 元素，共 109 个独立 PNG 素材。
- 在房屋编辑器的“墙面图案”区域选择主题，点击任意贴纸即可加入当前选定的墙面。
- 也可以继续上传自己的 PNG、JPG、WEBP 图片；上传素材保存在当前浏览器 IndexedDB。

墙贴编辑操作
- 鼠标直接拖动墙贴：移动位置。
- 按住 Shift 再拖动墙贴：旋转角度。
- 按住 Alt 再拖动墙贴：调整大小。
- 选中墙贴后，也可以用左右位置、上下位置、宽度、旋转角度滑块精确调整。
- 点击“复制图案”可复制当前墙贴；副本可以独立移动、缩放和旋转。
- 点击“删除选中图案”可删除当前墙贴。
- 选择后墙或左侧墙；客厅、卧室、卫生间分别保存自己的墙面素材。
- 同一张上传图片被复制到多个位置时会共用素材文件，删除一个摆放实例不会误删仍在使用的图片。

装修功能
- 毛坯墙保持未粉刷的中性浅灰色，可自行粉刷或贴图。
- 支持墙面、地板、装饰线与家具部位自由调色。
- 中式、美式、欧式、现代家具分别建模；每件家具可独立修改主体、布料和细节颜色。
- 3D 空白处拖动旋转房间视角，滚轮缩放。

数据说明
- 墙贴上传图片保存在当前浏览器 IndexedDB。
- 墙贴摆放位置、尺寸、旋转角度、房间家具和颜色设置保存在 localStorage。
- 数据仅保存在当前浏览器，不会自动跨设备同步。清理浏览器站点数据可能导致本地内容丢失。
