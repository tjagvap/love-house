更新方式（覆盖原 GitHub 仓库）
1. 先备份原来的项目文件夹。
2. 解压本压缩包。
3. 将压缩包根目录中的 index.html、bg.jpg、assets 文件夹和参考图片复制到原项目仓库根目录。
4. 保留原仓库的 .git 文件夹，不要删除。
5. 在原项目目录中运行：git add -A
6. 检查：git status
7. 提交：git commit -m "fix: 修复交互并加入天气昼夜和河流动态"
8. 推送：git push

全栈 Java 版（java-app/）
- 技术栈：Spring Boot 3.2.5 + Thymeleaf + Java 17 + Jackson，Maven Wrapper 免安装构建。
- 页面由 Java 模板渲染，场景所需图片、墙贴素材由 Spring 静态资源服务提供，视觉效果与静态版一致。
- 结构化数据（角色、宠物、漂流瓶、装修、天气昼夜、设置）由前端同步到 Java 后端，保存在 java-app/data/state.json；照片/视频/上传墙贴仍保存在本机 IndexedDB。
- REST 接口：GET /api/state、POST /api/state/bulk、POST /api/state/{key}、DELETE /api/state、GET /api/health。
- 运行：进入 java-app 目录，执行 .\mvnw.cmd spring-boot:run（Windows）或 ./mvnw spring-boot:run（bash），浏览器打开 http://localhost:8080。
- 打包：.\mvnw.cmd -DskipTests package，运行 java -jar target/love-house-1.0.0.jar。
- 首次运行会自动创建 data/state.json；清空数据可在应用“设置”中点击清空，或调用 DELETE /api/state。
