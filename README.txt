恋爱小屋 · 动态河畔与 3D 自由装修版

项目文件
- index.html：网站主程序
- bg.jpg：河畔场景背景（必须与 index.html 位于同一目录）
- assets/wall_stickers/：四套透明背景墙贴素材库
- style_reference.png：中式、美式、欧式、现代室内风格参考图
- material_reference.png：四种风格的材质与配色参考图

更新方式（覆盖原 GitHub 仓库）
1. 先备份原来的项目文件夹。
2. 解压本压缩包。
3. 将压缩包根目录中的 index.html、bg.jpg、assets 文件夹和参考图片复制到原项目仓库根目录。
4. 保留原仓库的 .git 文件夹，不要删除。
5. 在原项目目录中运行：git add -A
6. 检查：git status
7. 提交：git commit -m "fix: 修复交互并加入天气昼夜和河流动态"
8. 推送：git push

本次修复
- 交互物体悬停时，通过原背景局部放大提供反馈，不再添加阴影或高亮蒙层。
- 修复 Three.js 未加载时主脚本提前中断的问题；现在房间按钮、相册、设置、宠物、漂流瓶和其他监听仍会正常初始化。
- Three.js 改为依次尝试 jsDelivr、unpkg、BootCDN、字节/静态镜像、cdnjs 与 GitHub Raw 等线路。
- 如果所有 3D 引擎线路都不可用，会显示兼容房间预览，可旋转视角、滚轮缩放、添加家具、选中家具和调整颜色；成功加载 Three.js 后会自动切换到真实 WebGL 3D 场景。
- 恢复 7 个漂流瓶沿河道曲线持续漂流；河面增加持续移动的水光线。
- 树冠增加随风摆动的叶片效果。
- 增加天气：晴天、多云、小雨、飘雪、薄雾。
- 增加昼夜：默认白天 10:00；可自动交替、固定白天或固定黑夜，并可调整时间流速。
- 夜间场景会变暗，阳台暖光亮起，两位角色的剪影会出现在阳台，草坪区域也会压暗。
- 天气和时间按钮放在场景上方，可随时打开设置面板。

本地预览
1. 解压整个项目。
2. 在 index.html 所在目录打开 PowerShell。
3. 运行：python -m http.server 8000
4. 浏览器访问：http://localhost:8000

墙贴素材库
- 4 个主题：Hello Kitty、库洛米、玉桂狗、人鱼汉顿。
- 包含 109 个独立 PNG 贴纸元素、4 张主题整组贴纸图和素材清单。
- 在房屋编辑器的“墙面图案”区域选择主题，点击任意贴纸即可加入当前选定墙面。
- 支持上传自己的 PNG、JPG、WEBP 图片；上传素材保存到当前浏览器 IndexedDB。
- 贴纸可拖动、Shift+拖动旋转、Alt+拖动缩放，也可通过滑块精细调整；支持复制与删除。

装修功能
- 毛坯墙初始保持浅灰素墙，可自行粉刷或贴图。
- 支持墙面、地板、装饰线与家具部位自由调色。
- 中式、美式、欧式、现代家具按风格独立建模；每件家具可单独修改主体、布料和细节颜色。
- 真实 3D 模式下，空白处拖动旋转房间，滚轮缩放。

数据说明
- 照片、视频、上传墙贴保存在当前浏览器 IndexedDB。
- 角色、宠物好感度、漂流瓶、装修布局、颜色、天气和时间模式保存在当前浏览器 localStorage。
- 数据不会自动跨设备同步。清理浏览器站点数据前请先自行备份。
